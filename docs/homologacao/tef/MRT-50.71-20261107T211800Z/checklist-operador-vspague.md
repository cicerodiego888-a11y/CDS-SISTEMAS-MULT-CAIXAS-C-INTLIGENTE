# Checklist manual — operador V$Pague (sem automação)

Usar somente a UI já instalada. Não alterar cadastro, porta COM, PinPad ou reiniciar serviços nesta etapa de coleta.

## Dados a registrar (foto/print ou texto)

1. Identidade exibida do terminal/loja (esperado de referência: `LojaACB-TACB0120` / `Destaxa-LojaACB-TACB0120`).
2. Status do terminal: ativo / inativo / outro (copiar literal da tela).
3. Tela de dispositivos/PinPad: modelo listado (PPC-930?), estado (conectado/desconectado), porta COM selecionada.
4. Confirmação se a porta operacional do PinPad é `COM4`, outra COM, ou “não exibida”.
5. Qualquer alerta de comunicação PinPad ou Partner Cloud na tela.
6. Se existir painel de códigos: literais de estabelecimento, loja e terminal (copiar exatamente; não inferir).

## O que NÃO fazer

- Não clicar em gravar/salvar configuração.
- Não trocar porta COM.
- Não executar compra, sonda financeira, ou teste que dispare CRT.
- Não reiniciar V$PagueClient nesta coleta (se já estiver aberto, apenas consultar).
